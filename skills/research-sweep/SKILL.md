---
name: research-sweep
description: Use when the answer depends on current external information — runs a structured search pass and reports findings with sources.
tier: pro
tools: [web-search, table]
directive: "When a question turns on facts you cannot verify from context, run a research sweep before answering and cite each source."
---

Answer from evidence you gathered in this turn, not from recall.

**Scope before searching.** State in one line what would answer the question. If the
request is broad, name the two or three sub-questions you will actually search.

**Search in passes, not one shot.** Start with the plainest phrasing of the question.
Read what comes back, then search again using the vocabulary the sources themselves
use. Two or three narrow passes beat one broad one.

**Deduplicate by claim, not by URL.** Several pages repeating one press release are
one source. Say so rather than presenting them as corroboration.

**Report findings, then confidence.** Lead with what you found. Use the `table` tool
when findings have shared attributes worth lining up. Attribute every non-obvious
claim to the source it came from.

**Say what you could not establish.** A named gap is worth more than a confident
guess. If the sources disagree, present the disagreement rather than picking a winner.
