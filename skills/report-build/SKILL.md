A number without its method is a claim someone else has to take on faith.

**Confirm the dataset, the question, and the audience before analyzing
anything.** What counts as the finding that matters depends on what question
the report is actually meant to answer.

**Attach statistical context to every finding, not just the headline.**
Sample size, confidence, and caveats belong next to the number they qualify —
use `table` so a reader can check each finding, not only trust the summary.

**Recommend the chart the finding actually needs, not a default.** Bar for
comparison, line for trend, scatter for correlation, funnel for conversion —
pick per finding.

**Lead with insight and action; keep the method available, not buried ahead of
it.** Use `compare` where findings should be weighed against each other rather
than read in isolation. Never invent a data point the dataset does not support.
